======================================
Настройка и устранение неполадок камер
======================================

Данная инструкция описывает основные действия при настройке камер и устранении проблем с подключением в **Trassir**.

## Камера отображается красным цветом

В программе **Trassir** камеры могут отображаться красным цветом. Это означает, что с подключением или настройкой камеры возникла проблема.

Для определения причины откройте страницу проблемной камеры.

На странице камеры должна отображаться информация об ошибке, которая поможет определить причину неисправности.

Например, причиной может быть отсутствие настроенного пользователя или неправильный пароль.

![Ошибка подключения камеры в Trassir](images/cam-set-1.png)

## Подключение к веб-интерфейсу камеры

Если проблема связана с настройками самой камеры, необходимо перейти в её веб-интерфейс.

Откройте веб-интерфейс камеры по её IP-адресу и выполните авторизацию.

Для входа используется пользователь:

```text
Логин: admin
Пароль: 3140xyz1
```

Также может использоваться пароль:

```text
3140Xyz1!
```

После авторизации перейдите в раздел **Настройки**.

## Настройка времени через NTP

Одной из распространённых проблем является неправильное время на камере.

В настройках камеры необходимо проверить параметры времени и настроить синхронизацию через **NTP**.

После внесения изменений обязательно сохраните настройки.

![Настройка времени камеры через NTP](images/cam-set-2.png)

## Неправильный пароль в Trassir

Если камера работает через веб-интерфейс, но в **Trassir** отображается ошибка авторизации из-за неправильного пароля, необходимо заново добавить камеру с корректными данными.

Если проблемная камера уже добавлена в Trassir, сначала удалите её.

Для этого выберите камеру и нажмите кнопку **Удалить**.

![Удаление камеры в Trassir](images/cam-set-4.png)

После удаления перейдите в раздел:

```text
IP-устройства
```

Нажмите **Добавить вручную**.

## Добавление камеры вручную

При добавлении камеры необходимо выбрать производителя.

Например:

```text
HiWatch
```

Производителя камеры можно определить через её веб-интерфейс.

После выбора производителя нажмите **Autodetect**.

Укажите параметры подключения:

* IP-адрес камеры;
* логин;
* пароль.

Для пользователя укажите:

```text
admin
```

В поле пароля необходимо указать тот пароль, с которым удалось успешно авторизоваться в веб-интерфейсе камеры.

![Добавление IP-устройства в Trassir](images/cam-set-5.png)

![Настройка параметров камеры в Trassir](images/cam-set-6.png)

После добавления проверьте состояние камеры в Trassir. При корректных параметрах подключения камера должна начать отображаться без ошибки.

## Настройка новой камеры через SADP

Если камера новая и ещё не настроена, рекомендуется выполнять первоначальную настройку через **SADP**.

Программа SADP автоматически обнаруживает камеры, находящиеся в сети, и позволяет выполнить их основные настройки.

![Настройка камеры через SADP](images/cam-set-3.png)

С помощью SADP можно выполнить первоначальную настройку обнаруженной камеры, после чего добавить её в Trassir по IP-адресу и учётным данным.

## Порядок поиска неисправности

При возникновении проблемы рекомендуется выполнять проверку последовательно:

1. Открыть проблемную камеру в Trassir и посмотреть текст ошибки.
2. Проверить доступность веб-интерфейса камеры.
3. Проверить логин и пароль.
4. Проверить настройки времени и NTP.
5. Если в Trassir сохранён неправильный пароль — удалить камеру и добавить её заново.
6. При добавлении вручную указать правильного производителя, IP-адрес и учётные данные.
7. Для новой камеры выполнить первоначальную настройку через SADP.
