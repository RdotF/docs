=================================
Карты сети
=================================

Данная инструкция описывает использование программы **Algorius Net Viewer** для просмотра готовых карт сети.


Расположение программы
======================

Устанавливать программу **Algorius Net Viewer** не требуется.

Программа уже находится на сетевом ресурсе:

::

   \\10.0.3.8\admin_doc\Algorius.NetViewer.v.9.2.4\NetViewer


Для удобства работы достаточно создать ярлык на исполняемый файл.

Порядок действий:

1. Перейдите в папку с программой.
2. Найдите файл:

::

   NetViewer.exe

3. Создайте ярлык на рабочем столе.


Готовые карты сети
==================

Готовые карты сети находятся по пути:

::

   \\10.0.3.8\admin_doc\Algorius.NetViewer.v.9.2.4\NetViewer\Map


Использование карт
==================

Запустите программу **Algorius Net Viewer**.

Откройте папку с готовыми картами сети.

Для загрузки карты в программу достаточно:

1. Выбрать необходимый файл карты.
2. Перетащить его мышью в рабочее пространство программы **Algorius Net Viewer**.

После этого карта сети автоматически откроется и будет готова к просмотру.

.. note::

   Карты сети уже подготовлены и содержат актуальную информацию о сетевой инфраструктуре. Создание новых карт для просмотра не требуется.
